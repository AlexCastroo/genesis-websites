# Genesis Web Base — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plantilla Astro estática, multi-idioma y multi-negocio, con SEO técnico, GEO, accesibilidad, analítica con consentimiento y despliegue Docker + Nginx.

**Architecture:** Una fuente única de datos (`src/config/site.ts`, `src/i18n/*`, content collections) de la que se derivan rutas, `<head>`, JSON-LD, sitemap, `robots.txt`, `llms.txt`, RSS y redirects de Nginx. Una sola ruta dinámica (`src/pages/[...path].astro`) genera todas las páginas de todos los idiomas a partir de un planificador puro (`planPages`). Lógica en funciones puras de `src/lib/` testeadas con Vitest; componentes `.astro` solo componen.

**Tech Stack:** Astro 7 (estático), TypeScript 6 estricto, pnpm 11, Vitest 5, `@astrojs/sitemap`, `@astrojs/rss`, Fonts API de Astro (Inter vía fontsource), `astro:assets` + sharp, Docker (`node:22-alpine` → `nginxinc/nginx-unprivileged:stable-alpine`).

**Spec:** `docs/superpowers/specs/2026-09-30-web-base-design.md`

## Desviaciones respecto a la spec (decididas al planificar)

- **Astro 7** en lugar de 6: es la versión estable actual (7.3.x). Implicaciones: compilador Rust estricto (HTML mal cerrado = error), `compressHTML: 'jsx'` (los saltos de línea entre elementos inline se eliminan: usar `{' '}` si hace falta espacio), Markdown con Sätteri por defecto.
- **TypeScript 6** (no 7): `@astrojs/check` solo admite `^5 || ^6`.
- **Slug = nombre de fichero** (no campo `slug` en frontmatter): el loader `glob` usa `slug` del frontmatter como `id`, lo que rompería el idioma por carpeta. El fichero `es/tiendas-online.md` → id `es/tiendas-online` → URL `/servicios/tiendas-online`. Los nombres de fichero deben ser kebab-case en minúsculas (lo valida `check:i18n`).
- **FAQ = un YAML por pregunta** en `src/content/faq/{lang}/*.yaml` (loader `glob`), en lugar de un fichero por idioma: mismo patrón idioma-por-carpeta y `translationKey` que el resto.
- **Sin config `i18n` de Astro**: el enrutado i18n es propio (ruta dinámica + `routes.ts`); la config i18n de Astro no aporta nada y podría interferir. El sitemap sí recibe `i18n`.
- **Sin `Picture.astro` ni `Prose.astro`** propios: se usa `<Picture>` de `astro:assets` y la clase `.prose` directamente (YAGNI).
- **Nginx como plantilla** `deploy/nginx/default.conf.template` (envsubst de la imagen oficial) para inyectar `CONTACT_ORIGIN` en la CSP.

## Global Constraints

- Node `>=22.12.0` (`engines`); pnpm fijado en `packageManager: "pnpm@11.1.1"`.
- `pnpm-workspace.yaml`: `engineStrict: true`, `minimumReleaseAge: 1440`, `trustPolicy: no-downgrade`, `blockExoticSubdeps: true`, `strictDepBuilds: true`, `allowBuilds` solo `esbuild` y `sharp`.
- TypeScript: `astro/tsconfigs/strict`. Sin `any` explícito.
- Salida estática: `trailingSlash: 'never'`, `build.format: 'file'`. URLs sin barra final salvo `/`.
- Idioma por defecto sin prefijo (`/`), resto con prefijo (`/en`).
- Ningún dato (dominio, slug, texto visible, contacto) escrito en más de un sitio: dominio solo en `SITE.url`, slugs solo en `routes.ts`/nombres de fichero, textos UI solo en `src/i18n/ui/*.ts`.
- Nunca emitir propiedades vacías (`""`, `[]`, `{}`) en JSON-LD, `<meta>`, footer ni `llms.txt`.
- Un solo `<h1>` por página; `header`, `main`, `footer` hermanos.
- Todas las `<img>` con `alt`, `width`, `height`; imagen LCP `loading="eager" fetchpriority="high"`; resto lazy.
- Paleta base: blanco, negro, grises, rojo para enlaces/acento. Contraste texto ≥ 4,5:1. Solo modo claro.
- Breakpoints únicos: `600px` (sm), `900px` (md), `1200px` (lg). Mobile-first con `min-width`.
- Contenido visible sin JavaScript (`.reveal` solo oculta con clase `js` en `<html>`).
- Commits: Conventional Commits, terminados en `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Finales de línea LF (`.gitattributes`).

## Review Focus

1. **Config con un solo idioma** (quitar `en` de `locales`): el sitio compila, sin `hreflang`, sin `og:locale:alternate`, sin selector; los tests que usan un segundo idioma se saltan. → Test `hreflangLinks` con 1 alternate en Task 3; tests con `it.skipIf(!other)` en Tasks 2 y 7.
2. **Contenido que solo existe en un idioma**: la página se genera, no emite hreflang roto, el selector de idioma lleva a la home del otro idioma. → Test `contentAlternates` sin traducción en Task 7; `hreflangLinks` con 1 entrada en Task 3.
3. **Campos opcionales de `SITE` vacíos** (sin dirección, sin teléfono, redes vacías, `Organization` no local): el schema no contiene claves vacías ni propiedades de negocio local. → Tests `organizationNode` en Task 3.
4. **Borradores (`draft: true`) en producción**: excluidos de páginas, sitemap, RSS y `llms.txt`. → Test `isPublished` en Task 3 y `entryMeta` con draft en Task 5.
5. **`localStorage` bloqueado o corrupto** (modo privado, cookies bloqueadas, JSON inválido): el banner se muestra, nada lanza excepción. → Tests `readConsent`/`writeConsent` en Task 9.

- [ ] **Step 1: Crear `src/i18n/config.ts`**

```ts
export interface LocaleInfo {
  /** Name shown in the language switcher, in its own language. */
  label: string;
  /** BCP-47 code for <html lang>, hreflang and the sitemap. */
  hreflang: string;
  /** Open Graph locale. */
  og: string;
  dir: 'ltr' | 'rtl';
}

/** Add or remove a language here, then add its dictionary in ui/ and its routes in routes.ts. */
export const locales = {
  es: { label: 'Español', hreflang: 'es', og: 'es_ES', dir: 'ltr' },
  en: { label: 'English', hreflang: 'en', og: 'en_US', dir: 'ltr' },
} as const satisfies Record<string, LocaleInfo>;

export type Lang = keyof typeof locales;

export const defaultLocale: Lang = 'es';

export const localeCodes = Object.keys(locales) as Lang[];

export const isMultilingual = localeCodes.length > 1;

export function isLang(value: string | undefined): value is Lang {
  return value !== undefined && Object.hasOwn(locales, value);
}
```

```ts
import { defaultLocale, localeCodes, type Lang } from './config';
import { routes, type RouteKey } from './routes';
import { dictionaries, type UiKey } from './ui';

export type Alternates = Partial<Record<Lang, string>>;
export type Translate = (key: UiKey, vars?: Record<string, string | number>) => string;

export function useTranslations(lang: Lang): Translate {
  return (key, vars) => {
    const text = dictionaries[lang][key] ?? dictionaries[defaultLocale][key] ?? key;
    if (!vars) return text;
    return text.replace(/\{(\w+)\}/g, (match, name: string) =>
      name in vars ? String(vars[name]) : match,
    );
  };
}

/** '/', '/servicios', '/servicios/slug', '/en', '/en/services/slug'. Never a trailing slash. */
export function localizePath(routeKey: RouteKey, lang: Lang, slug?: string): string {
  const segments = [lang === defaultLocale ? '' : lang, routes[routeKey][lang], slug ?? ''].filter(
    Boolean,
  );
  return `/${segments.join('/')}`;
}

export function staticAlternates(routeKey: RouteKey): Alternates {
  return Object.fromEntries(localeCodes.map((lang) => [lang, localizePath(routeKey, lang)]));
}
```

```ts
export interface HreflangLink {
  hreflang: string;
  href: string;
}

export function absoluteUrl(siteUrl: string, path: string): string {
  if (/^https?:\/\//.test(path)) return path;
  const base = siteUrl.replace(/\/+$/, '');
  if (path === '' || path === '/') return `${base}/`;
  return `${base}${path.startsWith('/') ? path : `/${path}`}`;
}

export function pageTitle(title: string, siteName: string): string {
  return title.includes(siteName) ? title : `${title} — ${siteName}`;
}

export function readingMinutes(text: string, wordsPerMinute = 200): number {
  const words = text.trim().split(/\s+/).filter(Boolean).length;
  return Math.max(1, Math.round(words / wordsPerMinute));
}

/** hreflang links only make sense with 2+ language versions of the same page. */
export function hreflangLinks(
  alternates: Partial<Record<string, string>>,
  options: { siteUrl: string; defaultLang: string; hreflangOf: (lang: string) => string },
): HreflangLink[] {
  const entries = Object.entries(alternates).filter((entry): entry is [string, string] =>
    Boolean(entry[1]),
  );
  if (entries.length < 2) return [];
  const links = entries.map(([lang, path]) => ({
    hreflang: options.hreflangOf(lang),
    href: absoluteUrl(options.siteUrl, path),
  }));
  const defaultPath = alternates[options.defaultLang];
  if (defaultPath) {
    links.push({ hreflang: 'x-default', href: absoluteUrl(options.siteUrl, defaultPath) });
  }
  return links;
}
```

```ts
function isEmpty(value: unknown): boolean {
  if (value === undefined || value === null || value === '') return true;
  if (Array.isArray(value)) return value.length === 0;
  if (typeof value === 'object') return Object.keys(value).length === 0;
  return false;
}

/** Recursively removes undefined, null, '', [] and {} so no empty property reaches the markup. */
export function compact<T>(value: T): T {
  if (Array.isArray(value)) {
    return value.map((item) => compact(item)).filter((item) => !isEmpty(item)) as T;
  }
  if (value !== null && typeof value === 'object') {
    const out: Record<string, unknown> = {};
    for (const [key, item] of Object.entries(value)) {
      const cleaned = compact(item);
      if (!isEmpty(cleaned)) out[key] = cleaned;
    }
    return out as T;
  }
  return value;
}
```

```ts
/** Reads top-level `key: value` scalar lines. Nested/indented lines and comments are ignored. */
export function parseScalars(block: string): Record<string, string> {
  const data: Record<string, string> = {};
  for (const line of block.split(/\r?\n/)) {
    const match = /^([A-Za-z_][\w-]*):\s*(.*)$/.exec(line);
    if (!match) continue;
    let value = match[2].trim();
    const quoted =
      (value.startsWith('"') && value.endsWith('"')) || (value.startsWith("'") && value.endsWith("'"));
    if (quoted && value.length >= 2) value = value.slice(1, -1);
    data[match[1]] = value;
  }
  return data;
}

/** Minimal frontmatter reader for Node-side tooling (config, scripts). Astro parses content itself. */
export function readFrontmatter(source: string): Record<string, string> {
  const match = /^---\r?\n([\s\S]*?)\r?\n---/.exec(source);
  return match ? parseScalars(match[1]) : {};
}
```

```ts
import { defineCollection } from 'astro:content';
import { glob } from 'astro/loaders';
import { z } from 'astro/zod';

const faqItem = z.object({ q: z.string().min(1), a: z.string().min(1) });

const services = defineCollection({
  loader: glob({ base: './src/content/services', pattern: '**/*.md' }),
  schema: ({ image }) =>
    z
      .object({
        title: z.string().min(1),
        description: z.string().min(1),
        translationKey: z.string().min(1),
        order: z.number().int().default(100),
        /** 40–60 words, factual, self-contained: rendered as the opening definition (GEO). */
        summary: z.string().min(1),
        image: image().optional(),
        imageAlt: z.string().optional(),
        faqs: z.array(faqItem).default([]),
        updated: z.coerce.date(),
        draft: z.boolean().default(false),
      })
      .refine((data) => !data.image || Boolean(data.imageAlt), {
        message: 'imageAlt is required when image is set',
        path: ['imageAlt'],
      }),
});

const blog = defineCollection({
  loader: glob({ base: './src/content/blog', pattern: '**/*.md' }),
  schema: ({ image }) =>
    z
      .object({
        title: z.string().min(1),
        description: z.string().min(1),
        translationKey: z.string().min(1),
        published: z.coerce.date(),
        updated: z.coerce.date().optional(),
        author: z.string().min(1),
        image: image().optional(),
        imageAlt: z.string().optional(),
        tags: z.array(z.string()).default([]),
        draft: z.boolean().default(false),
      })
      .refine((data) => !data.image || Boolean(data.imageAlt), {
        message: 'imageAlt is required when image is set',
        path: ['imageAlt'],
      }),
});

const faq = defineCollection({
  loader: glob({ base: './src/content/faq', pattern: '**/*.yaml' }),
  schema: z.object({
    q: z.string().min(1),
    a: z.string().min(1),
    translationKey: z.string().min(1),
    category: z.string().optional(),
    order: z.number().int().default(100),
  }),
});

const legal = defineCollection({
  loader: glob({ base: './src/content/legal', pattern: '**/*.md' }),
  schema: z.object({
    title: z.string().min(1),
    description: z.string().min(1),
    /** 'legal-notice' | 'privacy' | 'cookies' (views and components look these up). */
    translationKey: z.string().min(1),
    order: z.number().int().default(100),
    updated: z.coerce.date(),
    noindex: z.boolean().default(false),
  }),
});

export const collections = { services, blog, faq, legal };
```

```ts
import { readdirSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { isLang } from '../i18n/config';
import type { RouteKey } from '../i18n/routes';
import { localizePath } from '../i18n/utils';
import { readFrontmatter } from './frontmatter';

/** Collections that produce public pages, and the route they live under. */
export const ROUTED_COLLECTIONS = {
  services: 'services',
  blog: 'blog',
  legal: 'legal',
} as const satisfies Record<string, RouteKey>;

export type RoutedCollection = keyof typeof ROUTED_COLLECTIONS;

export interface EntryMeta {
  path: string;
  lastmod?: Date;
  noindex: boolean;
  draft: boolean;
}

export interface ContentMeta {
  lastmod: Map<string, Date>;
  noindex: Set<string>;
}

export function entryMeta(
  collection: RoutedCollection,
  relativeFile: string,
  source: string,
): EntryMeta | null {
  const [lang, ...rest] = relativeFile.replace(/\\/g, '/').replace(/\.md$/, '').split('/');
  if (!isLang(lang) || rest.length === 0) return null;
  const data = readFrontmatter(source);
  const raw = data.updated || data.published;
  const date = raw ? new Date(raw) : undefined;
  return {
    path: localizePath(ROUTED_COLLECTIONS[collection], lang, rest.join('/')),
    lastmod: date && !Number.isNaN(date.getTime()) ? date : undefined,
    noindex: data.noindex === 'true',
    draft: data.draft === 'true',
  };
}

function listMarkdown(dir: string): string[] {
  try {
    return (readdirSync(dir, { recursive: true }) as string[]).filter((file) => file.endsWith('.md'));
  } catch {
    return [];
  }
}

/** Read at config time (Node) to feed the sitemap with lastmod and noindex exclusions. */
export function collectContentMeta(contentDir: URL): ContentMeta {
  const root = fileURLToPath(contentDir);
  const meta: ContentMeta = { lastmod: new Map(), noindex: new Set() };
  for (const collection of Object.keys(ROUTED_COLLECTIONS) as RoutedCollection[]) {
    const dir = join(root, collection);
    for (const file of listMarkdown(dir)) {
      const entry = entryMeta(collection, file, readFileSync(join(dir, file), 'utf8'));
      if (!entry || entry.draft) continue;
      if (entry.lastmod) meta.lastmod.set(entry.path, entry.lastmod);
      if (entry.noindex) meta.noindex.add(entry.path);
    }
  }
  return meta;
}
```

```ts
import type { CollectionEntry } from 'astro:content';
import { isLang, localeCodes, type Lang } from '../i18n/config';
import type { RouteKey } from '../i18n/routes';
import { localizePath, staticAlternates, type Alternates } from '../i18n/utils';
import { entryLang, entrySlug } from './content';

export const STATIC_PAGES = ['home', 'services', 'about', 'contact', 'faq', 'blog'] as const satisfies readonly RouteKey[];
export type StaticKind = (typeof STATIC_PAGES)[number];

interface PageBase {
  path: string;
  lang: Lang;
  alternates: Alternates;
}

export type StaticPage = PageBase & { kind: StaticKind };
export type ServicePage = PageBase & { kind: 'service'; entry: CollectionEntry<'services'> };
export type PostPage = PageBase & { kind: 'post'; entry: CollectionEntry<'blog'> };
export type LegalPage = PageBase & { kind: 'legal'; entry: CollectionEntry<'legal'> };
export type Page = StaticPage | ServicePage | PostPage | LegalPage;

interface Translatable {
  id: string;
  data: { translationKey: string };
}

function langOf(entry: { id: string }): Lang {
  const lang = entryLang(entry.id);
  if (!isLang(lang) || !entrySlug(entry.id)) {
    throw new Error(
      `Content entry "${entry.id}" must live in a locale folder (${localeCodes.join(', ')})`,
    );
  }
  return lang;
}

export function entryPath(routeKey: RouteKey, entry: { id: string }): string {
  return localizePath(routeKey, langOf(entry), entrySlug(entry.id));
}

export function contentAlternates(
  routeKey: RouteKey,
  entries: Translatable[],
  translationKey: string,
): Alternates {
  const alternates: Alternates = {};
  for (const entry of entries) {
    if (entry.data.translationKey === translationKey) {
      alternates[langOf(entry)] = entryPath(routeKey, entry);
    }
  }
  return alternates;
}

function contentPages<K extends string, E extends Translatable>(
  kind: K,
  routeKey: RouteKey,
  entries: E[],
) {
  return entries.map((entry) => ({
    kind,
    entry,
    lang: langOf(entry),
    path: entryPath(routeKey, entry),
    alternates: contentAlternates(routeKey, entries, entry.data.translationKey),
  }));
}

/** Pure: every public page of the site, for every locale. */
export function planPages(input: {
  services: CollectionEntry<'services'>[];
  posts: CollectionEntry<'blog'>[];
  legal: CollectionEntry<'legal'>[];
}): Page[] {
  const statics: StaticPage[] = localeCodes.flatMap((lang) =>
    STATIC_PAGES.map((kind) => ({
      kind,
      lang,
      path: localizePath(kind, lang),
      alternates: staticAlternates(kind),
    })),
  );
  const pages: Page[] = [
    ...statics,
    ...contentPages('service', 'services', input.services),
    ...contentPages('post', 'blog', input.posts),
    ...contentPages('legal', 'legal', input.legal),
  ];
  const seen = new Set<string>();
  for (const page of pages) {
    if (seen.has(page.path)) throw new Error(`Duplicate page path "${page.path}"`);
    seen.add(page.path);
  }
  return pages;
}
```

```ts
import type { FaqItem } from './schema';

export interface LlmsLink {
  title: string;
  url: string;
  note?: string;
}

export interface LlmsInput {
  name: string;
  description: string;
  tagline: string;
  facts: string[];
  services: LlmsLink[];
  faqs: FaqItem[];
  posts: LlmsLink[];
  contact: string[];
  languages: LlmsLink[];
}

const link = (item: LlmsLink) => `- [${item.title}](${item.url})${item.note ? `: ${item.note}` : ''}`;

/** https://llmstxt.org layout: H1, blockquote summary, free text, then H2 sections. */
export function buildLlms(input: LlmsInput): string {
  const lines = [`# ${input.name}`, '', `> ${input.description}`, '', input.tagline, ''];
  const section = (title: string, body: string[]) => {
    if (body.length > 0) lines.push(`## ${title}`, '', ...body, '');
  };
  section('About', input.facts.map((fact) => `- ${fact}`));
  section('Services', input.services.map(link));
  section('FAQ', input.faqs.flatMap((faq) => [`### ${faq.q}`, '', faq.a, '']));
  section('Blog', input.posts.map(link));
  section('Contact', input.contact.map((item) => `- ${item}`));
  section('Other languages', input.languages.map(link));
  return `${lines.join('\n').replace(/\n{3,}/g, '\n\n').trimEnd()}\n`;
}
```

```ts
export const CONSENT_KEY = 'consent.v1';

export type ConsentValue = 'granted' | 'denied';

export function readConsent(storage: Pick<Storage, 'getItem'> | undefined): ConsentValue | null {
  try {
    const raw = storage?.getItem(CONSENT_KEY);
    if (!raw) return null;
    const parsed = JSON.parse(raw) as { value?: unknown };
    return parsed.value === 'granted' || parsed.value === 'denied' ? parsed.value : null;
  } catch {
    return null;
  }
}

export function writeConsent(
  storage: Pick<Storage, 'setItem'> | undefined,
  value: ConsentValue,
  now: Date = new Date(),
): void {
  try {
    storage?.setItem(CONSENT_KEY, JSON.stringify({ value, date: now.toISOString() }));
  } catch {
    // Storage blocked or full: the choice lasts for this page view only.
  }
}
```

```ts
import { readConsent, writeConsent, type ConsentValue } from './consent';

declare global {
  interface Window {
    dataLayer: unknown[];
    gtag?: (...args: unknown[]) => void;
  }
}

export function safeStorage(): Storage | undefined {
  try {
    return window.localStorage;
  } catch {
    return undefined;
  }
}

/** Google Consent Mode v2: everything denied until the visitor accepts. */
export function initAnalytics(gaId: string): void {
  window.dataLayer = window.dataLayer || [];
  window.gtag = function gtag() {
    // gtag.js requires the `arguments` object itself, not an array.
    window.dataLayer.push(arguments);
  };

  const stored = readConsent(safeStorage());
  window.gtag('consent', 'default', {
    ad_storage: 'denied',
    ad_user_data: 'denied',
    ad_personalization: 'denied',
    analytics_storage: stored === 'granted' ? 'granted' : 'denied',
    wait_for_update: 500,
  });
  window.gtag('js', new Date());
  window.gtag('config', gaId);

  const load = () => {
    const script = document.createElement('script');
    script.async = true;
    script.src = `https://www.googletagmanager.com/gtag/js?id=${encodeURIComponent(gaId)}`;
    document.head.append(script);
  };
  if ('requestIdleCallback' in window) window.requestIdleCallback(load, { timeout: 3000 });
  else setTimeout(load, 1500);

  document.addEventListener('click', (event) => {
    const target = (event.target as Element | null)?.closest<HTMLElement>('[data-track]');
    if (target?.dataset.track) trackEvent(target.dataset.track);
  });
}

export function setConsent(value: ConsentValue): void {
  writeConsent(safeStorage(), value);
  window.gtag?.('consent', 'update', { analytics_storage: value });
}

export function trackEvent(name: string, params?: Record<string, unknown>): void {
  if (readConsent(safeStorage()) !== 'granted') return;
  window.gtag?.('event', name, params);
}
```

```ts
export interface ContentRecord {
  file: string;
  lang: string;
  translationKey: string;
  title?: string;
  description?: string;
}

export function findDuplicateKeys(source: string): string[] {
  const counts = new Map<string, number>();
  for (const match of source.matchAll(/^\s*['"]([^'"]+)['"]\s*:/gm)) {
    counts.set(match[1]!, (counts.get(match[1]!) ?? 0) + 1);
  }
  return [...counts].filter(([, count]) => count > 1).map(([key]) => key);
}

export function invalidFileNames(collection: string, files: string[], langs: readonly string[]): string[] {
  const errors: string[] = [];
  for (const file of files) {
    const [lang, ...rest] = file.split('/');
    if (!lang || !langs.includes(lang) || rest.length !== 1) {
      errors.push(`${collection}/${file}: must be <locale>/<file> with locale in [${langs.join(', ')}]`);
    } else if (!/^[a-z0-9]+(?:-[a-z0-9]+)*\.(md|ya?ml)$/.test(rest[0]!)) {
      errors.push(`${collection}/${file}: file name must be lowercase kebab-case (it becomes the URL slug)`);
    }
  }
  return errors;
}

export function contentParity(collection: string, records: ContentRecord[], langs: readonly string[]): string[] {
  const warnings: string[] = [];
  const byKey = new Map<string, Set<string>>();
  for (const record of records) {
    if (!record.translationKey) {
      warnings.push(`${record.file}: missing translationKey`);
      continue;
    }
    byKey.set(record.translationKey, (byKey.get(record.translationKey) ?? new Set()).add(record.lang));
  }
  for (const [key, present] of byKey) {
    for (const lang of langs) {
      if (!present.has(lang)) warnings.push(`${collection}: "${key}" has no ${lang} version`);
    }
  }
  return warnings;
}

export function lengthWarnings(label: string, title?: string, description?: string): string[] {
  const warnings: string[] = [];
  if (title !== undefined && (title.length < 30 || title.length > 60)) {
    warnings.push(`${label}: title has ${title.length} chars (recommended 30–60)`);
  }
  if (description !== undefined && (description.length < 120 || description.length > 160)) {
    warnings.push(`${label}: description has ${description.length} chars (recommended 120–160)`);
  }
  return warnings;
}
```

```ts
/** Regex-based checks over Astro's generated HTML (attributes always double-quoted). */
export function auditHtml(html: string): string[] {
  const issues: string[] = [];
  const h1Count = (html.match(/<h1[\s>]/g) ?? []).length;
  if (h1Count !== 1) issues.push(`expected 1 <h1>, found ${h1Count}`);
  if (!/<html[^>]*\slang="[^"]+"/.test(html)) issues.push('missing <html lang>');
  if (!/<title>[^<]+<\/title>/.test(html)) issues.push('missing <title>');
  if (!/<meta name="description" content="[^"]+"/.test(html)) issues.push('missing meta description');
  if (!/<link rel="canonical" href="https?:\/\/[^"]+"/.test(html)) issues.push('missing absolute canonical');
  for (const match of html.matchAll(/<script type="application\/ld\+json">([\s\S]*?)<\/script>/g)) {
    try {
      JSON.parse(match[1]!);
    } catch {
      issues.push('invalid JSON-LD');
    }
  }
  for (const match of html.matchAll(/<img\b[^>]*>/g)) {
    const tag = match[0];
    if (!/\salt="/.test(tag)) issues.push(`<img> without alt: ${tag.slice(0, 80)}`);
    if (!/\swidth="/.test(tag) || !/\sheight="/.test(tag)) {
      issues.push(`<img> without width/height: ${tag.slice(0, 80)}`);
    }
  }
  if (/\shref=""/.test(html)) issues.push('empty href');
  return issues;
}
```

```ts
import type { Redirect } from '../config/redirects';

const SAFE_PATH = /^\/[A-Za-z0-9\-._~/%]*$/;
const SAFE_TARGET = /^[A-Za-z0-9\-._~/%:?=&#+]+$/;

function validate(rule: Redirect): void {
  const label = `redirect ${rule.from} → ${rule.to}`;
  if (!rule.from.startsWith('/')) throw new Error(`${label}: "from" must start with "/"`);
  if (!SAFE_PATH.test(rule.from)) throw new Error(`${label}: "from" has invalid characters`);
  if (rule.from.length > 1 && rule.from.endsWith('/')) {
    throw new Error(`${label}: "from" must not have a trailing slash (Nginx strips it first)`);
  }
  if (!rule.to.startsWith('/') && !/^https?:\/\//.test(rule.to)) {
    throw new Error(`${label}: "to" must be a path or an http(s) URL`);
  }
  if (!SAFE_TARGET.test(rule.to)) throw new Error(`${label}: "to" has invalid characters`);
  if (rule.from === rule.to) throw new Error(`${label}: points to itself`);
}

/** Renders src/config/redirects.ts as Nginx exact-match 301 locations. */
export function renderNginxRedirects(list: Redirect[]): string {
  const seen = new Set<string>();
  const lines = list.map((rule) => {
    validate(rule);
    if (seen.has(rule.from)) throw new Error(`redirect ${rule.from}: duplicate "from"`);
    seen.add(rule.from);
    return `location = ${rule.from} { return 301 ${rule.to}; }`;
  });
  return `${['# GENERATED from src/config/redirects.ts by scripts/gen-nginx-redirects.ts — do not edit', ...lines].join('\n')}\n`;
}
```

```nginx
# Rendered by the nginx image's envsubst at start-up (only defined env vars are replaced).
# ${CONTACT_ORIGIN} = origin of PUBLIC_CONTACT_ENDPOINT, e.g. https://formspree.io (may be empty).

map $uri $cache_control {
    default                     "public, max-age=86400";
    ~^/_astro/                  "public, max-age=31536000, immutable";
    ~\.html$                    "no-cache";
    ~^/(robots|llms)\.txt$      "public, max-age=3600";
    ~\.xml$                     "public, max-age=3600";
}

server {
    listen 8080;
    server_name _;
    root /usr/share/nginx/html;
    index index.html;

    server_tokens off;
    absolute_redirect off;
    charset utf-8;
    charset_types text/plain text/css text/xml application/xml application/rss+xml application/javascript application/json image/svg+xml;

    gzip on;
    gzip_vary on;
    gzip_comp_level 6;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml application/xml application/rss+xml application/javascript application/json image/svg+xml;

    add_header Cache-Control $cache_control always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "DENY" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Permissions-Policy "camera=(), microphone=(), geolocation=(), interest-cohort=()" always;
    add_header Cross-Origin-Opener-Policy "same-origin" always;
    add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline' https://www.googletagmanager.com; connect-src 'self' https://*.google-analytics.com https://*.analytics.google.com https://*.googletagmanager.com ${CONTACT_ORIGIN}; img-src 'self' data: https://*.google-analytics.com https://*.googletagmanager.com; style-src 'self' 'unsafe-inline'; font-src 'self'; form-action 'self' ${CONTACT_ORIGIN}; frame-ancestors 'none'; base-uri 'self'; object-src 'none'" always;
    # Enable ONLY once HTTPS works on the final domain (browsers cache it for a year):
    # add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;

    # Canonical URLs have no trailing slash (except "/").
    rewrite ^/(.+)/$ /$1 permanent;

    include /etc/nginx/snippets/redirects.conf;

    location / {
        try_files $uri $uri.html $uri/ =404;
    }

    error_page 404 /404.html;
    location = /404.html {
        internal;
    }
}
```

````md
# Crear un proyecto nuevo desde la base

1. **Copiar la base** a un repo nuevo (sin historial):
   ```bash
   git clone --depth 1 <repo-genesis> mi-negocio && cd mi-negocio
   rm -rf .git && git init -b main
   pnpm install
   ```
2. **Datos del negocio** — `src/config/site.ts`:
   - `url`: dominio definitivo, sin barra final. Es la única fuente del dominio.
   - `entity.schemaType`: `Organization`, `LocalBusiness` o un subtipo de schema.org (`Restaurant`, `Dentist`, `LegalService`, `Store`…). `entity.local: true` si hay local físico (emite dirección, geo, horarios, `priceRange`).
   - Contacto, dirección, `geo`, `openingHours`, redes (vacías = se omiten), `aiTraining`.
3. **Idiomas** — `src/i18n/config.ts`:
   - Quitar un idioma: borrar su entrada en `locales`, su diccionario en `src/i18n/ui/` (y en `ui/index.ts`), su columna en `routes.ts` y su carpeta en cada `src/content/*/`.
   - Añadir un idioma: entrada en `locales`, `src/i18n/ui/<lang>.ts` tipado `Record<UiKey, string>`, registrarlo en `ui/index.ts`, slugs en `routes.ts`, carpeta `<lang>/` en cada colección.
   - TypeScript falla si falta alguna pieza.
4. **Textos** — `src/i18n/ui/*.ts`. Títulos 30–60 caracteres, descripciones 120–160 (`pnpm check:i18n` avisa).
5. **Contenido** — `src/content/`:
   - Nombre de fichero = slug de la URL (kebab-case, minúsculas).
   - Misma `translationKey` en todas las traducciones de una entrada (así se enlazan los `hreflang`).
   - `summary` de servicios: 40–60 palabras, factual y autocontenido (es lo que citan los buscadores de IA).
   - `draft: true` oculta la entrada en producción.
   - Revisar las plantillas legales con un asesor.
6. **Marca visual** — `src/styles/tokens.css` (colores semánticos, tipografía, radios…) y la fuente en `astro.config.ts` (`fonts`). Mantener contraste ≥ 4,5:1.
7. **Imágenes** — sustituir `public/favicon.svg`, `public/favicon.ico`, `public/apple-touch-icon.png` (180×180), `public/logo.png` (cuadrado ≥ 112 px), `public/og-default.jpg` (1200×630) y `src/assets/hero.jpg`. `pnpm tsx scripts/generate-placeholders.ts` regenera los genéricos.
8. **Variables de entorno** — copiar `.env.example` a `.env`:
   - `PUBLIC_GA_ID` (vacío = sin analítica ni banner).
   - `PUBLIC_CONTACT_ENDPOINT` (vacío = sin formulario) y `CONTACT_ORIGIN` (origen del endpoint para la CSP).
9. **Redirecciones** de URLs antiguas — `src/config/redirects.ts`.
10. **Comprobar** — `pnpm check && pnpm build && pnpm verify`.
11. **Desplegar** — `docker compose up -d --build` en el servidor, detrás del proxy/TLS que se configure a mano. Activar HSTS en `deploy/nginx/default.conf.template` solo cuando HTTPS funcione.
12. Seguir [el checklist de lanzamiento](launch-checklist.md).
````
